# AegisOps
AegisOps — защищённая платформа эксплуатации микросервисов Это миниатюрная production-платформа для условного интернет-магазина или платёжного сервиса. Она автоматически разворачивает приложение в Kubernetes, проверяет безопасность каждой поставки, собирает телеметрию, обнаруживает атаки и демонстрирует реакцию системы на инциденты.
