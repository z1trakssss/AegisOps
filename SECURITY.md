# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Send a private report
through the repository security advisory form and include reproduction steps,
affected versions, expected impact and any proposed mitigation.

This repository is an educational security lab. Its fault-injection modes and
attack scenarios are intentional, documented and disabled by default. Never
expose a lab deployment to the public internet or run experiments against
systems you do not own or have explicit permission to test.

## Supported versions

Only the latest revision of the default branch receives security fixes.
